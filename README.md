# IMDB Sentiment Analysis CI/CD

This repository contains a small sentiment analysis project trained on a balanced IMDb review dataset and configured to run automatically on GitHub Actions.

## Project structure

```bash
your-project/
│
├── data/
│   └── imdb_balanced_10k.csv (generated by `train.py` if missing)
├── model/
│   └── model artifacts saved by training
├── train.py
├── predict.py
├── requirements.txt
├── README.md
└── .github/
    └── workflows/
        └── train-and-upload.yml
```

## How it works

1. `train.py` downloads a balanced IMDb dataset if `data/imdb_balanced_10k.csv` does not already exist.
2. It trains a feedforward neural network on TF-IDF features.
3. It saves:
   - `model/model.pt`
   - `model/vectorizer.pkl`
   - `model/config.json`
   - `model/metrics.json`
4. GitHub Actions installs dependencies, runs `train.py`, then uploads artifacts to Hugging Face Hub.

## Run locally

```bash
python -m pip install -r requirements.txt
python train.py
python predict.py --text "That movie was exciting and well acted."
```

## GitHub Actions

The workflow is defined in `.github/workflows/train-and-upload.yml`.

Set the following GitHub Action secret in your repository settings:

- `HF_TOKEN` — Hugging Face access token
- `HF_REPO_ID` (optional) — repository slug for Hugging Face, e.g. `your-user/imdb-sentiment-nn`

If `HF_REPO_ID` is not provided, the workflow uses the GitHub repository name as the Hub repo ID.

## Notes

- The project targets `main` or `master` pushes.
- No manual uploads to Hugging Face are required after initial setup.
- The workflow will automatically create the Hugging Face repo if it does not already exist.
